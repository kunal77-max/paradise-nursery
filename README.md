# Paradise Nursery

## Project Overview

Paradise Nursery is an online houseplant shopping application where users can browse plants, explore different categories, and add their favorite plants to a shopping cart.

## Features

- Landing page introducing Paradise Nursery
- Company information page
- Houseplants organized into categories
- Product images, names, and prices
- Add-to-cart functionality
- Dynamic cart item count
- Increase and decrease product quantities
- Remove items from the shopping cart
- Automatic calculation of item totals and cart total
- Responsive navigation between pages

## Technologies Used

- React
- JavaScript
- HTML and CSS
- Redux Toolkit
- React Redux
- React Router DOM
